# Dot – Grow Together

Dot is a shared habit-tracking platform designed for couples. It helps two people build healthy routines, track daily habits, monitor progress, and achieve their goals together.

## About the Project

The idea behind Dot is to make habit tracking more engaging by allowing partners to manage their personal habits while sharing their daily progress with each other.

## Features

- **Personal Habit Tracking** – Create and manage daily habits.
- **Shared Dashboard** – View your partner's habits and progress.
- **Progress Tracking** – Monitor completed habits and daily consistency.
- **Streak Tracking** – Keep track of consecutive successful days.
- **Daily Activities** – Organize and manage daily routines.
- **Shared Goals** – Work together towards common goals.

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd Dot
```

### 2. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Setup Backend

Make sure Java 21 and Maven are installed.

```bash
cd backend
mvn spring-boot:run
```

### 4. Environment Configuration

Configure your MongoDB connection and other environment variables before running the backend.
